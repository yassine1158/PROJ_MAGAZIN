Comment faire

  1. Même Wi-Fi. Connectez le téléphone au même Wi-Fi que cet ordinateur (pas en données mobiles).
  2. Ouvrez l'adresse. Scannez le QR code avec l'appareil photo, ou tapez l'adresse dans le navigateur (Chrome, Safari…).
  3. Chaque personne se connecte avec son propre compte (nom d'utilisateur et mot de passe). Les comptes se créent dans Réglages › Utilisateurs.
  4. Astuce : dans le menu du navigateur, choisissez « Ajouter à l'écran d'accueil » pour l'ouvrir comme une application.
{% icone 'alerte' %}
La première fois, Windows demande d'autoriser l'accès au réseau : cochez « Réseaux privés », puis cliquez sur « Autoriser ».

Le logiciel doit rester ouvert sur cet ordinateur pendant que les téléphones l'utilisent.

Le téléphone n'arrive pas à ouvrir la page ?

  • Vérifiez que le téléphone est bien sur le Wi-Fi du magasin, et que le logiciel est ouvert sur cet ordinateur.
  • Sur l'ordinateur, le Wi-Fi doit être en « Réseau privé » : Paramètres › Réseau et Internet › Wi-Fi › votre réseau › Réseau privé.
  • Si quelqu'un a cliqué sur « Annuler » quand Windows a posé la question : Panneau de configuration › Pare-feu Windows Defender › Autoriser une application, puis cochez « {{ PRODUIT }} » dans la colonne « Privé ».
  • L'adresse peut changer quand la box ou le routeur Wi-Fi redémarre : revenez sur cette page pour voir la nouvelle.
